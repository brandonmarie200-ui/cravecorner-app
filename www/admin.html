Food safety

Review seller declarations and documents. Read the honesty rules below before approving anything.

Honesty rules — non-negotiable CraveCorner never independently verifies food-safety compliance. A reviewed declaration means an admin looked at the submitted paperwork — it is not a health inspection and does not mean the seller complies with local law. Sellers are solely responsible for complying with their state and local cottage-food rules (rules vary by state). Never present a shop as "verified safe" or "health-inspected."

Featured shops

Not available yet — schema gap (documented, not invented)

cc_shops has no is_featured column, so this panel does not query or write one. To enable featured shops before launch, an owner should run this migration in the Supabase SQL editor (it is not run yet):

-- Featured shops (Stage 6 note — run once, then refresh the view)
alter table public.cc_shops
  add column if not exists is_featured boolean not null default false;

-- Expose the flag on the public materialized view (edit the view
-- definition in 00_schema.sql to select s.is_featured, then):
refresh materialized view public.cc_shops_public;

After the migration, this panel will list shops with a feature/unfeature toggle. Until then, no featured-shop UI ships to buyers — nothing fake is shown.
